CUBEJUMP V1 — playable web prototype

Confirmed scope implemented in this prototype:
- 6 built-in levels.
- 3 crystals in every built-in level.
- Touch jump control plus keyboard Space/Up for desktop testing.
- Local completion/crystal progress.
- Level editor with block, spike, platform, crystal, delete, undo, save and test.
- Editor limits custom levels to 3 crystals.
- Local editor save.
- Offline cache when served over HTTP/HTTPS.
- Responsive phone/tablet layout.

Open index.html in a browser for a quick test. For full offline/PWA behavior, serve the folder over HTTP/HTTPS.
This is not yet an Android AAB/APK. The next packaging step is to wrap the web project into an Android app and verify it on Android.
